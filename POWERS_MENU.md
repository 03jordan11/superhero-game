# Powers menu

Powers now lives in the **TAB gameplay menu**, alongside Gear, Attributes, Journal, and Map. The Powers button has been removed from Pause. See [GAMEPLAY_MENU.md](GAMEPLAY_MENU.md) for the implemented locks, save migration, file inventory, and testing checklist; [POWERS_DESIGN.md](POWERS_DESIGN.md) remains the design reference.

The existing cards and detail page now show **Movement / Body / Elemental** and all nine documented branches: Super Jump, Speed, Flight, Strength, Mind, Laser Eyes, Frost, Fire, and Electric. Each has its documented core description and three named upgrade slots. Flight upgrade 3 is still undefined. Text remains in `localization/powers.json`, with live locale updates through `powers_text.gd`.

New games start with Power Jump unlocked; all other powers are locked. Any core can be purchased independently; upgrades are sequential within a branch. Costs remain one test token per purchase. Existing charged jumping, boosted sprinting, flight, flight boost, wall running, ground slam/Dive Bomb, car lifting/throwing, and the encounter marker now require their documented purchases. Unfinished effects are explicitly marked planned and remain purchasable as prerequisite tiers; the Strength and Speed cores now also grant +5 points to their respective attributes. Stamina now limits boosted traversal; Endurance halves running drain only, and sprint must be released or toggled off before recovery. Greater Jump (Super Jump upgrade 1) doubles charged-jump height and the power's ballistic forward-distance contribution. Air Jump (Super Jump upgrade 2) now provides one immediate jump while airborne, with half the current full-jump launch power, replenished on landing. Bounding (Super Jump upgrade 3) now chains fast, forceful landings with a forgiving Jump input window, full jump height, and gradually declining horizontal momentum. Dive Bomb is excluded. All three Super Jump upgrades are implemented; see BOUNDING.md for tuning. Other planned combat and heat mechanics remain unimplemented. Attribute points earned on each new level can be spent in Attributes.

The player owns progression through `PlayerPowerController`, and purchases now immediately affect existing ability gates and autosave. Console `add pp` grants power points without autosaving. Use `save` and `load` to persist/restore test progression; Play starts fresh. Old default-true gameplay flags do not bypass progression; legacy menu branches migrate as documented in the gameplay-menu guide.

The three upgrade pips still indicate purchased tiers. Locked cards remain selectable. The embedded detail pane scrolls independently, keeping the nine power cards visible. TAB/Escape closes the menu and resumes play; Xbox R3 opens/closes, B closes, and LB/RB switch tabs. All gameplay-menu bindings are configurable.

Run `tests/test_gameplay_menu.gd`, `tests/test_powers_page.gd`, `tests/test_power_token_saves.gd`, and `tests/test_powers_localization.gd` for progression, real ability locks, navigation, save compatibility, and localization checks.
